# marketing-zeno

Everything marketing, website growth, launch and store listing for Zeno lives here. No file in this folder is code; where a step needs a code change, the spec is here and the engineering session applies it.

| File | What |
|---|---|
| `MARKETING_ZENO.md` | the prioritised plan: 6 tiers, each item with what / why / deliverable / who / done-when |
| `GROWTH_LOG.md` | dated log of every check run, with the numbers, plus the "needs the owner" table (G0-G14) |
| `deploy/owner-checklist.md` | domain, Vercel, DNS, Search Console, Bing, analytics, waitlist webhook, brand profiles; one line each with the exact value |
| `keywords/keyword-architecture.md` | brand / money / long-tail map, one page per intent |
| `research/domain-check-2026-10-01.md` | what zeno.app serves; RDAP on 12 candidate names |
| `research/competitor-pricing-2026-10-01.md` | YNAB, Monarch, Rocket Money facts read live, with verdicts for the 5 compare pages |
| `research/serp-checks-2026-10-01.md` | page-1 results for 20 queries and who holds them |
| `research/cancel-url-audit-2026-10-01.md` | HTTP status of all 204 curated cancel URLs |
| `content/money-pages/*.md` | full drafts of `/subscription-tracker`, `/cancel-subscriptions`, `/free-trial-reminders`, `/budgeting` + porting and link-mesh rules |
| `content/cancel-guides/top-20-verified.md` | verified steps, URLs, traps and sources for the first 20 guides |
| `content/cancel-guides/template-spec.md` | the guide page upgrade (fields, sections, JSON-LD, sitemap) |
| `content/blog/outlines.md` | first four posts, each with a parent money page |
| `content/about-page.md` | founder page brief |
| `content/llms.txt` | draft for `public/llms.txt` |
| `launch/product-hunt.md`, `show-hn.md`, `reddit-posts.md`, `directories.md`, `outreach-list.md`, `day-1-runbook.md` | launch assets; the owner posts |
| `store/store-listing-check.md`, `store/screenshot-plan.md` | limits re-checked; 8-frame screenshot plan |
| `ads/search-test.md` | the paid test, gated, with stop rules |

Rails that bind every file: "No bank login required" is the required phrase; banned: "100% on-device", "we never see your data", automatic/background discovery claims, "no Plaid ever", invented statistics, "Most popular"/urgency, "encrypted sync". Competitor claims carry their verification date.
